Ruby formatting,
settled once.

Tuxedo is a fast, opinionated Ruby code formatter written in Rust. Put it in CI with a layout your team chose once, and “move this space” never comes up in code review again.

Get started View on GitHub 
# Gemfile
gem "tuxedo-r", require: false

$ bundle install
$ bundle exec tuxedo format .
$ gem install tuxedo-r
$ tuxedo format .
# Download the archive for your platform from GitHub Releases,
# unpack it and put `tuxedo` on your PATH.
$ tar xf tuxedo-x86_64-unknown-linux-gnu.tar.xz
$ ./tuxedo-x86_64-unknown-linux-gnu/tuxedo format .

One layout, in both directions

Tuxedo breaks what is too long and joins what was broken by hand, so the same code always comes out the same way. This is its real output, with line_length = 60.

Optimized for the next diff

Where more than one layout is defensible, Tuxedo picks the one that produces the smaller, clearer diff when the code changes later.

All-or-nothing expansion

A collection fits on one line or puts every element on its own. Never bin-packed, so adding one element never reflows its neighbours.

Block indentation

Continuations sit at a fixed indent, never aligned under a bracket or a name, so renaming a variable does not reindent the literal beneath it.

Safe by construction

Every output is parsed again and compared with the original syntax tree. If the meaning changed, the file is left untouched.
